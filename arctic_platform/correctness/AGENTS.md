# Correctness Harness Agent Notes

Use descriptive, stable filenames for maintained code and tests, such as `check_runner_lora_save0.py`. Do not include agent IDs, thread IDs or hashes in code filenames. Content-addressed reference records and immutable run receipts are data, not code, and retain their integrity keys.

Read [HF reference onboarding](docs/hf-reference-onboarding.md) before changing reference preparation, compact records, calibration, or cached-reference regression.
